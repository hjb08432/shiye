# 拾页 · 小说推荐工具

输入喜欢的类型、氛围或一句模糊的感觉，从 **网络小说、现实向文学、类型出版** 三条轨道里，找到下一本书。

这是一个纯前端、离线可用的单页工具。无需安装依赖，直接用浏览器打开 `index.html` 即可。

## 能做什么

- **自然语言选书**：支持“想看点轻松的悬疑，最好短一点，不要 BE”这类描述，也支持直接输入书名或作者。
- **多条件筛选**：书库类型、阅读状态、篇幅、排序；书目覆盖网络小说、现实向文学与类型出版。
- **有内容的推荐**：每个结果给出匹配度、命中偏好，以及编辑评分、分项评分、书评、优点、注意点和读者口碑关键词。
- **正版资源入口**：每本书提供官方阅读平台、微信读书、豆瓣读书、京东图书或 WorldCat 馆藏检索等入口。
- **书架与夜间模式**：收藏保存在浏览器本地；支持日间 / 夜间阅读主题。

## 使用

1. 用浏览器打开 `index.html`。
2. 输入类型或从快捷标签开始，点击「替我找书」。
3. 点开任意一本书，查看完整书评、资源与相似作品。
4. 点书签把书放进「书架」。

所有资源链接都跳转到平台站内搜索或图书页面。连载状态、版权与库存会变化，请以平台为准。

## 文件结构

```text
index.html          页面结构
assets/styles.css   视觉与响应式样式
assets/data.js      43 本书目、评分、书评与配色
assets/engine.js    偏好解析、匹配、筛选、相似作品与资源链接
assets/app.js       页面渲染与交互
```

## 关于内容

- 书目、评分、长评、优点 / 注意点与口碑关键词均为编辑策展内容，**不是豆瓣或任何平台的官方评分**。
- 不抓取、不转载第三方书评，不提供盗版下载或资源搬运。
- 封面为根据每本书配色生成的文字版式，不使用受版权保护的封面图片。

书单与资源入口最后校对：2026 年 11 月。
